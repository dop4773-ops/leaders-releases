# 연차관리 시스템 (오프라인 데스크톱판)

서버 연결 없이 PC 한 대에서 동작하는 연차관리 프로그램입니다. Windows 7 이상(32비트/64비트) 지원.

## 설치

1. [Releases](../../releases)에서 최신 `LeaveManager_Setup_x.y.z.exe`를 받습니다.
2. 실행합니다. "Windows의 PC 보호" 경고가 뜨면 **추가 정보 → 실행**을 누릅니다. (코드 서명 인증서가 없어서 뜨는 경고입니다)
3. 처음 실행하면 빈 데이터로 시작합니다. 초기 관리자 계정은 `admin` / `admin1234`이며, 로그인 후 반드시 비밀번호를 바꾸세요.

## 기존 데이터 불러오기

Google 시트에서 **파일 → 다운로드 → Microsoft Excel(.xlsx)** 로 받은 뒤, 프로그램 메뉴 **파일 → 데이터 가져오기**에서 그 파일을 선택합니다.
교체 전 데이터는 자동으로 백업됩니다.

## 데이터와 백업

- 데이터는 `%APPDATA%\연차관리 시스템\data\data.json`에 저장되고, 메뉴 **파일 → 데이터 폴더 열기**로 열 수 있습니다.
- 실행할 때마다 `backup` 폴더에 하루 1개씩 백업되고, 최근 30개가 유지됩니다.
